# Manifest

- `mcp-server/` supervised Career MCP command registry skeleton.
- `playwright-worker/` visible browser automation worker.
- `cloudflare-worker/` edge/auth gateway.
- `tool/` Windows supervisor scripts.
- `docs/` operational and bootstrap docs.
- `ops/` environment templates and Cloudflare notes.
- `app/` Symfony-oriented PHP model/service skeleton using default `App\` namespace.
- `profile/` reusable profile sample.
- `script/` legacy compatibility scripts.
- `doc/` legacy architecture and safety notes.
